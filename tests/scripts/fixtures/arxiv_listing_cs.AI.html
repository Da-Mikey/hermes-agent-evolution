[1] arXiv:2610.37720 [pdf, html]
Title: LRMoE: Demand-Side Load Re-Calibration for Efficient MoE Training on Memory-Constrained Nodes
Jiaming Hu, Zhida Jiang
Comments: 31 pages, 7 figures, 10 tables
Subjects: Artificial Intelligence (cs.AI); Distributed, Parallel, and Cluster Computing (cs.DC); Machine Learning (cs.LG)

Sparse Mixture-of-Experts (MoE) models offer scalable capacity, but uneven routing creates computation and communication bottlenecks. We present LRMoE, a memory-aware MoE training system that reduces cumulative MoE-layer training time by 21.2-44.8%.

[2] arXiv:2610.37721v2
Title: Tool-Use Budgets for Autonomous Agents: Rationing < Caching < Planning
Ada Okoye
Subjects: Machine Learning (cs.LG); Computation and Language (cs.CL)

We study how an agent should ration tool calls across a long horizon. A planning-first policy dominates both caching and fixed rationing on three benchmark suites.

Title: Verifier Independence in Self-Improving Coding Agents
Marta Reyes, Sun-Hee Park
Comments: Accepted at an agent-evaluation workshop
Subjects: Computation and Language (cs.CL)

Self-grading agents inflate pass rates. We measure the gap when the verifier shares the author's context and show a cheap independence budget closes most of it.
